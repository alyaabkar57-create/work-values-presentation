# سلوكيات وقيم العمل

عرض تقديمي عربي تفاعلي من 12 شريحة، مبني بـ HTML و CSS و JavaScript خالصة، يعمل مباشرة في المتصفح.

## الملفات

- `index.html` — المحتوى والشرائح ومكتبة أيقونات SVG.
- `styles.css` — نظام التصميم، التخطيطات، الحركات، الاستجابة، وإعدادات الطباعة.
- `script.js` — التنقل والتفاعل.

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً ثابتاً:

```bash
npx serve .
```

## الاختصارات

| المفتاح | الوظيفة |
|---|---|
| `←` | الشريحة التالية (اتجاه RTL) |
| `→` | الشريحة السابقة |
| `Space` / `PageDown` | التالي |
| `PageUp` | السابق |
| `Home` / `End` | البداية / النهاية |
| `F` | ملء الشاشة |
| `P` | الطباعة أو الحفظ كـ PDF |

كما تتوفر أزرار التنقل وقائمة الشرائح أسفل الشاشة، وتفاعل بطاقات "مواقف من بيئة العمل" بالضغط عليها.

## النشر على Cloudflare Pages

المستودع خاص، لذا يُنصح بالنشر برمجياً عبر Wrangler (لا يحتاج صلاحية GitHub App):

```bash
npm install -g wrangler
wrangler login
wrangler pages deploy . --project-name work-values-presentation
```

أو من لوحة Cloudflare:
**Workers & Pages → Create → Pages → Connect to Git → GitHub → اختر المستودع → Deploy**
(قد يتطلب تثبيت تطبيق Cloudflare على المستودع الخاص).

> الخطوط من Google Fonts والصور من Unsplash، لذا يفضّل الاتصال بالإنترنت عند عرض الشرائح.
